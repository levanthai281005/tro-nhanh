# Quy trình cho các loại công việc

Mỗi file mô tả quy trình chuẩn cho một loại việc lặp lại trong dự án. Trước khi bắt tay,
đọc file tương ứng và làm đúng thứ tự các bước.

| Loại việc | File |
|---|---|
| Chuyển một trang từ prototype sang repo này | `PORT_PAGE_FROM_PROTOTYPE.md` |
| Dựng feature mới không có mẫu prototype | `ADD_NEW_FEATURE.md` |
| Làm form nhập liệu | `CREATE_FORM.md` |
| Nối một endpoint mới từ backend | `INTEGRATE_API_ENDPOINT.md` |
| Tạo một module NestJS mới ở `apps/api` | `CREATE_API_MODULE.md` |
| Thay đổi cấu trúc dữ liệu (bảng, cột, index) | `ADD_DB_MIGRATION.md` |
| Tách file vượt giới hạn dòng | `REFACTOR_LARGE_FILE.md` |
| Trước khi báo hoàn thành | `PRE_HANDOFF_CHECKLIST.md` |

Nguyên tắc chung cho mọi loại việc: **lập kế hoạch trước, chờ duyệt, rồi mới viết code**.
Chỉ làm đúng phạm vi được giao; thấy vấn đề ngoài phạm vi thì báo lại thay vì tự sửa.
